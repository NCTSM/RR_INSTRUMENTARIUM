# TRACE ORACLE

**Reactive Relics — Experimental Device**

TRACE ORACLE is a portable electronic instrument developed within the Reactive Relics instrumentarium.

The device combines sensing, visual feedback, interaction and sound in a compact handheld artefact. It explores the idea of a technological oracle: a machine that receives traces from its environment and transforms them into signals, states and responses.

---

## CONCEPT

TRACE ORACLE is conceived as a **portable divination instrument**.

Rather than presenting information in a conventional technological interface, the device turns sensing and interaction into an ambiguous process of interpretation.

The performer interacts with the object through its physical interface while the device produces visual and sonic responses.

The machine becomes an intermediary between **body, signal and interpretation**.

---

## HARDWARE

### Microcontroller

* ESP32
* Display
* Physical keyboard / button interface
* Audio output

The ESP32 provides the computational core of the instrument and manages interaction, visual feedback and sound generation.

---

## AUDIO

TRACE ORACLE includes an independent audio output generated by the ESP32.

Sound forms part of the device's response system rather than functioning only as an indication or notification.

The sonic output contributes to the interpretation of the machine's states.

---

## VISUAL INTERFACE

A display provides visual information generated by the instrument.

The combination of screen, physical controls and sound creates a closed interaction loop between performer and device.
